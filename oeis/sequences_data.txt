The rows for n=0,1,2 give
n^3 = binomial(n,0)*0 + binomial(n,1)*1 + binomial(n,2)*6 + binomial(n,3)*6,
n^3 = binomial(n-1,0)*1 + binomial(n-1,1)*7 + binomial(n-1,2)*12 + binomial(n-1,3)*6,
n^3 = binomial(n-2,0)*8 + binomial(n-2,1)*19 + binomial(n-2,2)*18 + binomial(n-2,3)*6. etc.
-----------------------------------
Let S_m(n) be sum of powers: S_m(n) = 1^m + 2^m + 3^m + ... + n^m, then
S_3(n) = 0*(binomial(n+1,1)-binomial(1,1))
       + 1*(binomial(n+1,2)-binomial(1,2))
       + 6*(binomial(n+1,3)-binomial(1,3))
       + 6*(binomial(n+1,4)-binomial(1,4)).
S_3(n) = 1*(binomial(n,2)-binomial(0,2))
       + 7*(binomial(n,3)-binomial(0,3))
       + 12*(binomial(n,4)-binomial(0,4))
       + 6*(binomial(n,5)-binomial(0,5)).
S_3(n) = 8*(binomial(n-1,2)-binomial(-1,2))
       + 19*(binomial(n-1,3)-binomial(-1,3))
       + 18*(binomial(n-1,4)-binomial(-1,4))
       + 6*(binomial(n-1,5)-binomial(-1,5)).
S_3(n) = 27*(binomial(n-2,2)-binomial(-2,2))
       + 37*(binomial(n-2,3)-binomial(-2,3))
       + 24*(binomial(n-2,4)-binomial(-2,4))
       + 6*(binomial(n-2,5)-binomial(-2,5)).
